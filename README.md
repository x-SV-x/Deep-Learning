# Contents : 
1. **Single Layer Perceptron** - Implementation of a single layer perceptron from scratch.
2. **Multi Layer Perceptron** - **Binary Classification** into the two classes - cancer/not-cancer using ANNs (Multi layer perceptrons) trained on a ovarian tumor dataset. I also implment different regularization techniques : $Dropout$, $Early$ $stopping$, $L1$ $and$ $L2$ $regularization$, $Batch$ $normalization$; and evaluate performances for each.
3. **Convolutional Neural Networks** - A CNN model implemented on a MRI dataset for Alzheimers. I also implment different regularization techniques : $Dropout$, $Early$ $stopping$, $L1$ $and$ $L2$ $regularization$, $Batch$ $normalization$; and evaluate performances for each. [Data Source - Reduced version of this data](https://www.kaggle.com/datasets/lukechugh/best-alzheimer-mri-dataset-99-accuracy)
4. **A. Standard CNN architectures and transfer learning** - Implemented $VGG16$, $VGG19$ and improved accuracy of the original model using, a. $BatchNorm$, $Dropout$, smaller Dense layers. b. Using $GlobalAveragePooling2D$ instead of $Flatten$ c. $Transfer$ $learning$. [Data Source - Reduced version of this data (same Alzheimers dataset as 3)](https://www.kaggle.com/datasets/lukechugh/best-alzheimer-mri-dataset-99-accuracy) <br> **B. Deep CNN ensemble model/Stacking** - we use 3 CNN models on the same Alzheimers dataset as the first stack and then use their results as an input to a simple Multi Layer Perceptron which acts as a second stacking layer.
5. **XAI methods** - I take a pretrained $ResNet50$ model (imported from $torchvision$) and implement the following XAI methods on a test image of a dog - $Occlusion$, $Integrated$ $Gradients$, $Guided$ $Backpropagation$, $Grad-CAM$, $Grad-CAM++$, $LIME$ and $SHAP$.
